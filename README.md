# Weather Stylist Bot 👗🌦️

A Telegram bot that suggests an outfit based on the current weather in your city. Share your location, and the bot geocodes it, fetches live weather data, and asks Google's Gemini model to recommend a fitting outfit — in English or Ukrainian.

## Features

- 🌍 **Language selection** — English or Ukrainian, chosen on `/start`
- 🚻 **Gender selection** — outfit suggestions tailored to male/female
- 📍 **Location-based weather** — reverse-geocodes your Telegram location to a city via OpenStreetMap (Nominatim)
- 🌡️ **Live weather data** — temperature, description, humidity, and wind speed from OpenWeatherMap
- 🤖 **AI outfit suggestions** — a short, emoji-flavored outfit recommendation generated by Google Gemini
- 🇺🇦 Full bilingual UI (English / Ukrainian)

## How it works

1. User sends `/start` and picks a language and gender.
2. User taps the "Send my location" button.
3. The bot reverse-geocodes the coordinates to a city name (Nominatim).
4. The bot fetches current weather for that city (OpenWeatherMap).
5. The bot prompts Gemini with the weather data and gender, and replies with a short outfit suggestion.


## Requirements

- Python 3.10+
- A Telegram bot token ([@BotFather](https://t.me/BotFather))
- An [OpenWeatherMap](https://openweathermap.org/api) API key
- A [Google Gemini](https://ai.google.dev/) API key

## Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Maksimuson/Weather-Stylist-Bot.git
   cd <your-repo>
   ```

2. Create a `.env` file in the project root:

   ```env
   TelegramBotToken=your_telegram_bot_token
   WeatherAPIKey=your_openweathermap_api_key
   GEMINI_API_KEY=your_gemini_api_key
   ```

3. Run the bot:

   ```bash
   python main.py
   ```

## Notes

- The Gemini model used is `gemini-3.1-flash-lite` — fast and cheap, with no announced retirement date at the time of writing.
- Weather descriptions are requested in Russian (`lang=ru`) from the OpenWeatherMap API regardless of the bot's UI language; adjust `weather.py` if you'd like this to follow the user's chosen language instead.
- User state (language/gender) is kept in memory only and will reset when the bot restarts.
