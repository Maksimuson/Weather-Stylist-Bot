# Weather Stylist Bot 🧥⛅

A Telegram bot that suggests an outfit based on the current weather in your city. Share your location, and the bot finds your city, fetches live weather data, and asks Google's Gemini model to recommend a fitting outfit, in English or Ukrainian.

👉 **Try it:** [@weather_stylist_for_you_bot](https://t.me/weather_stylist_for_you_bot)

## Features

- 🌍 **Language selection**: English or Ukrainian, chosen on `/start`
- 🚻 **Gender selection**: outfit suggestions tailored to male/female
- 📍 **Location-based weather**: reverse-geocodes your Telegram location to a city via OpenStreetMap (Nominatim)
- 🌡️ **Live weather data**: temperature, description, humidity and wind speed from OpenWeatherMap
- 🤖 **AI outfit suggestions**: a short, emoji-flavored recommendation generated by Google Gemini
- ☁️ **Always on, free hosting**: runs as a webhook on Vercel serverless functions
- 💾 **Persistent settings**: language and gender are stored in Redis (Upstash), so they survive between requests

## How it works

1. User sends `/start` and picks a language and gender.
2. User taps the "Send my location" button.
3. The bot reverse-geocodes the coordinates to a city name (Nominatim).
4. The bot fetches current weather for that city (OpenWeatherMap).
5. The bot prompts Gemini with the weather data and gender, and replies with a short outfit suggestion.

In production, Telegram sends every message to the Vercel function as a webhook `POST` request. The function processes the update with aiogram and replies, then shuts down.

## Tech stack

- Python 3.10+
- [aiogram 3](https://docs.aiogram.dev/) (Telegram Bot framework)
- [FastAPI](https://fastapi.tiangolo.com/) (webhook endpoint)
- [Google Gemini API](https://ai.google.dev/) (`google-genai`)
- [OpenWeatherMap API](https://openweathermap.org/api)
- Nominatim / geopy (reverse geocoding)
- Vercel (hosting) and Upstash Redis (user settings)

## Environment variables

| Variable | Required | Description |
| --- | --- | --- |
| `TelegramBotToken` | yes | Bot token from [@BotFather](https://t.me/BotFather) |
| `WeatherAPIKey` | yes | OpenWeatherMap API key |
| `GEMINI_API_KEY` | yes | Google Gemini API key |
| `TELEGRAM_SECRET` | no | Secret string to verify that webhook requests come from Telegram |
| `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` | no | Redis credentials (`KV_REST_API_URL` / `KV_REST_API_TOKEN` also work). Without them, settings are kept in memory and reset on restart |

## Run locally

Locally the bot uses polling, so no server or public URL is needed.

1. Clone the repository:

   ```
   git clone https://github.com/Maksimuson/Weather-Stylist-Bot.git
   cd Weather-Stylist-Bot
   ```

2. Install dependencies:

   ```
   pip install -r requirements.txt
   ```

3. Create a `.env` file in the project root (never commit it):

   ```
   TelegramBotToken=your_telegram_bot_token
   WeatherAPIKey=your_openweathermap_api_key
   GEMINI_API_KEY=your_gemini_api_key
   ```

4. Run the bot:

   ```
   cd src
   python main.py
   ```

> A Telegram bot can use either polling or a webhook, not both. `main.py` removes the webhook on start, so stop it before relying on the Vercel deployment again, and re-set the webhook afterwards.

## Deploy to Vercel (free, always on)

1. Push the repository to GitHub.
2. On [vercel.com](https://vercel.com), choose **Add New → Project** and import the repository.
3. Add the environment variables from the table above (`TelegramBotToken`, `WeatherAPIKey`, `GEMINI_API_KEY`, optionally `TELEGRAM_SECRET`) and deploy.
4. In the project's **Storage** tab, create an **Upstash Redis** database (free plan) and connect it to the project, then **Redeploy**.
5. In **Settings → Deployment Protection**, disable Vercel Authentication so Telegram can reach the endpoint.
6. Register the webhook by opening this URL in your browser (replace the placeholders):

   ```
   https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=https://<your-project>.vercel.app/webhook
   ```

   If you set `TELEGRAM_SECRET`, append `&secret_token=<the same value>`.

7. Check the status at `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getWebhookInfo`. `last_error_message` should be empty.

## Notes

- The Gemini model used is `gemini-3.1-flash-lite`, which is fast and cheap. You can change `MODEL_NAME` in `src/hendlers.py`.
- Weather descriptions are requested in Russian (`lang=ru`) from the OpenWeatherMap API regardless of the bot's UI language; adjust `src/weather.py` if you'd like this to follow the user's chosen language.
- Free-tier quotas (Gemini, OpenWeatherMap, Vercel, Upstash) apply. If a quota runs out, the bot replies that the styling assistant is temporarily unavailable.
- Keep tokens and API keys out of the repository. If a token is ever exposed, revoke it in @BotFather and update it in Vercel.
